📋 Key Technologies

  • face-api.js: JavaScript library for face detection and emotion recognition
  • TinyFaceDetector: Fast face detection model optimized for real-time performance
  • FaceExpressionNet: Deep learning model trained to recognize 7 facial expressions
  • Fusion Algorithm: Weighted voting system combining face (45%), voice (35%), and text (20%)
  • Platform: Browser-based real-time processing (no server upload required for face detection)

😊 Supported Emotions

  • Happy 😊 - Smiling, raised cheeks
  • Sad 😢 - Downturned mouth, furrowed brows
  • Angry 😠 - Tensed face, raised brows
  • Fearful 😨 - Wide eyes, open mouth
  • Disgusted 🤢 - Wrinkled nose, raised upper lip
  • Surprised 😮 - Raised eyebrows, open mouth
  • Neutral 😐 - Relaxed expression
