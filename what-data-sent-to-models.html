↓
📹 captureFrame() called
Grabs current frame from video element
↓
🎬 HTML5 Video Element
Contains live video stream's current frame
↓

videoElement (HTMLVideoElement)

Extracts and detects faces
↓
🧠 MODEL 2: FaceExpressionNet
Classifies facial expressions
↓

Emotion + Confidence + Scores

🎯 EXACTLY What is Sent to Models

// From: frontend/src/services/emotionApi.ts export async function detectFaceEmotion(videoEl: HTMLVideoElement) { const faceapi = (window as any).faceapi; // ← THIS IS WHAT IS SENT TO MODELS: const detection = await faceapi .detectSingleFace(videoEl, new faceapi.TinyFaceDetectorOptions({ inputSize: 224, // Image size: 224×224 pixels scoreThreshold: 0.5 // Confidence threshold: 50% }) ) .withFaceExpressions(); return detection; }

🔍 Model 1: TinyFaceDetector

Input Received:
  • Video element with current frame
  • Input size: 224×224 pixels
  • Score threshold: 0.5 (50%)
Processing Steps:
  • Extract RGB pixel data from frame
  • Resize to 224×224 (if needed)
  • Normalize pixel values (0-1)
  • Pass through CNN layers
  • Generate confidence score
Output:
  • Face bounding box (x, y, width, height)
  • Confidence score (0-1)
  • Face landmarks (68 points)

😊 Model 2: FaceExpressionNet

Input Received:
  • Detected face region (cropped)
  • Aligned face (48×48 pixels)
  • Grayscale or RGB
Processing Steps:
  • Extract face region from frame
  • Align face (rotation correction)
  • Resize to 48×48 pixels
  • Normalize pixel values
  • Pass through CNN layers
  • Apply softmax activation
Output:
  • 7 emotion probabilities (0-1)
  • Emotions: neutral, happy, sad, angry, fearful, disgusted, surprised
  • Top emotion + confidence

⚙️ What Happens Inside the Models

TinyFaceDetector Processing:

Input Frame (640×480 RGB) ↓ [Extract Pixels] Get raw RGB values ↓ [Resize] Scale to 224×224 ↓ [Normalize] Convert RGB (0-255) → (0-1) ↓ [Conv Layer 1] 16 filters, 3×3 kernel ↓ [MaxPool] 2×2 stride ↓ [Conv Layer 2] 32 filters, 3×3 kernel ↓ [Conv Layer 3] 64 filters, 3×3 kernel ↓ [Flatten] Convert to vector ↓ [Dense Layer] 128 units ↓ Output: [x, y, width, height, confidence]

FaceExpressionNet Processing:

Detected Face Region (48×48 pixels) ↓ [Extract Face] Crop from original frame ↓ [Align Face] Rotate/correct orientation ↓ [Normalize] Pixel values (0-1) ↓ [Conv Layer 1] 16 filters ↓ [Conv Layer 2] 32 filters ↓ [MaxPool] 2×2 ↓ [Conv Layer 3] 64 filters ↓ [Conv Layer 4] 128 filters ↓ [GlobalAvgPool] Average all values ↓ [Dense Layer] 256 units, ReLU ↓ [Dropout] 50% regularization ↓ [Output Layer] 7 units, Softmax ↓ Output: [neutral%, happy%, sad%, angry%, fearful%, disgusted%, surprised%]
Aspect Details
What is sent? HTMLVideoElement (current frame from video stream)
Frame size? Original: 640×480 (resized by model to 224×224)
Format? RGB color space (3 channels: Red, Green, Blue)
How many models? 2 models: TinyFaceDetector → FaceExpressionNet
Where is processing? Browser (client-side only)
Sent to server? NO - Never leaves the user's device
How fast? 30-50ms for TinyFaceDetector + 50-80ms for FaceExpressionNet
GPU required? NO - Uses TensorFlow.js for CPU inference

🔒 Privacy Alert

The video frame NEVER leaves your device!

  • All processing happens in browser
  • Models run locally on your computer
  • Image data is never sent to any server
  • Only the final emotion result is sent to backend
  • Your camera data is completely private

📋 Complete Data Flow Summary

Face Recording Stops ↓ captureFrame() extracts current video frame ↓ videoRef.current (HTMLVideoElement) ↓ detectFaceEmotion(videoRef.current) ↓ TinyFaceDetector receives frame, outputs: { x, y, width, height, confidence } ↓ FaceExpressionNet receives face region, outputs: { neutral: 0.1, happy: 0.85, sad: 0.05, ... } ↓ ModalityResult created: { emotion: "Happy", confidence: 85, scores: [...] } ↓ ONLY THIS is sent to backend (no image data): POST /api/emotion/analyze { face_emotion: { modality: 'face', emotion: 'Happy', confidence: 85, scores: [...] } } ↓ Backend stores emotion record in MongoDB
