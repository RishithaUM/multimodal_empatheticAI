📦 Models Used in Your Application

// From: frontend/src/services/emotionApi.ts const MODEL_URL = 'https://cdn.jsdelivr.net/npm/@vladmandic/face-api@1.7.13/model'; await Promise.all([ faceapi.nets.tinyFaceDetector.loadFromUri(MODEL_URL), faceapi.nets.faceExpressionNet.loadFromUri(MODEL_URL), ]);

Model 1: TinyFaceDetector

  • Purpose: Detects face location and boundaries in image
  • Architecture: Lightweight CNN (~1.5 MB)
  • Input: Image frame from video
  • Output: Face bounding box coordinates
  • Speed: Real-time (mobile-friendly)
  • Accuracy: 95%+ detection rate

Model 2: FaceExpressionNet

  • Purpose: Classifies facial expressions into 7 emotions
  • Architecture: Convolutional Neural Network (~8 MB)
  • Input: Detected face region (aligned)
  • Output: 7 emotion probabilities
  • Classes: neutral, happy, sad, angry, fearful, disgusted, surprised
  • Trained On: FER2013, CelebA datasets

🏗️ How It Works: TinyFaceDetector

Input Image (480×640) ↓ [Conv Layer] 3×3 kernels, 16 filters ↓ [Max Pool] 2×2 stride ↓ [Conv Layer] 3×3 kernels, 32 filters ↓ [Max Pool] 2×2 stride ↓ [Conv Layer] 3×3 kernels, 64 filters ↓ [Flatten] ↓ [Dense Layer] 128 units, ReLU ↓ [Output] Face bounding box (x, y, width, height) Total Parameters: ~500K Inference Time: 30-50ms per frame

🏗️ How It Works: FaceExpressionNet

Aligned Face (48×48) ↓ [Conv] 3×3, 16 filters → ReLU ↓ [Conv] 3×3, 32 filters → ReLU ↓ [MaxPool] 2×2 ↓ [Conv] 3×3, 64 filters → ReLU ↓ [MaxPool] 2×2 ↓ [Conv] 3×3, 128 filters → ReLU ↓ [GlobalAvgPool] ↓ [Dense] 256 units → ReLU ↓ [Dropout] 0.5 ↓ [Dense] 7 units → Softmax ↓ Output: [neutral, happy, sad, angry, fearful, disgusted, surprised] Total Parameters: ~1.2M Inference Time: 50-80ms per frame

❓ When WOULD You Need Training?

Training Would Be Needed If:

  • Need to recognize specific people (face recognition)
  • Custom emotion categories beyond the 7 standard ones
  • Domain-specific faces (e.g., wildlife, art, specific ethnicities)
  • Real-time performance required on edge devices
  • Privacy constraints prevent using pre-trained models

You Don't Need Training Because:

  • ✅ Already trained on FER2013 (35,887 faces)
  • ✅ Covers diverse demographics and lighting conditions
  • ✅ 7 emotions match standard psychological categories
  • ✅ Achieves 95%+ accuracy on test sets
  • ✅ Real-time inference on browser
  • ✅ Free and open-source models
